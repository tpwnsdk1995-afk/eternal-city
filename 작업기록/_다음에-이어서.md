## 원작 포맷 메모 (해독 완료, scratchpad/ecdec.py)
- .dat/.dta = 스프라이트 컨테이너: u8 0, u16 count, count×(u32 rid, u32 off), blobs
- blob: u32 L, u32 X(픽셀 섹션 시작), u16 A(파트수), u16 B, u16 0, (A-1)×u32 파트 오프셋
- part: u16 C(블록수=방향 8 등), u16 D, u16 0, (C-1)×u32 블록 오프셋 / block: u16 n, n×u32 프레임 오프셋
- frame: u16 nlayers, nlayers×(u32 ptr, u32 pixoff) / layer: u8 type, u16 w, u16 h, s16 ox, s16 oy, h행×[u16 n][n×(skip,run)]
- 픽셀: RGB565 리틀엔디안, X + pixoff(바이트). 확인: 00012.dat id 4305 = 남자 기본 몸 8방향×132프레임 26×62.
- 파일 번호대(썸네일 스캔 기준): 03xxx=아이템 아이콘, 04/05/06xxx=캐릭터·몬스터 스프라이트, 07~09xxx=소품/구조물. .btx=19바이트 헤더 뒤 DDS(DXT1) 지형 텍스처 묶음, s0/s1 .dat=그냥 WAV 효과음, .mak/.flg=파일 1개짜리 ZIP(맵 격자/플래그), .bcd=커서 추정, ab .dat/.bgd/.bgi=미해독. 사용자 승인: 전부 참고해서 써도 됨(2026-09-16).

## 추출 파이프라인 (tools/ec-extract.py)
- `python tools/ec-extract.py <key> --strip` → tools/out/<key>_strip.png (정면 블록 전 프레임, 번호 표시) → 눈으로 idle/walk/aim/death 프레임 고름
- SPRITES[key] = file, rid, parts(A2 몬스터는 part0=스프라이트, part1=큰 미리보기 → [0]만), frames
- `python tools/ec-extract.py <key>` → public/art/<key>.png, 셀 크기는 자동(사용 프레임 최대 범위) → 출력된 frameW/frameH를 artOverrides.ts 에 적용
- 게임 쪽: ART_OVERRIDES 시트에 `scale`(원본 62px 인물을 48px 그림 인물 크기에 맞춤 = 0.6), Enemy 는 artScale(def.tex) 곱함, 히트 원은 this.height 기준
- zombie_casual_f 프레임 지도(40프레임/방향): 0~7 걷기, 8~13 공격, 14~15 ?, 16~28 대기, 29~34 죽음(34 누움), 35~39 피격
- 스크린샷: scratchpad/zz-shot.spec.ts + zz-shot.config.ts 를 e2e/ 로 복사 → `npx playwright test -c e2e/zz-shot.config.ts zz-shot.spec.ts` (설치된 Edge 사용, playwright 브라우저 다운로드 불필요) → e2e/out/*.png. **끝나면 다시 e2e/ 에서 빼둘 것**(npm run e2e 가 집어감).
- 도구 주의: Bash 도구 heredoc 안에서는 백슬래시가 한 단계 접혀 파이썬 문자열 패치가 깨진다 → 백슬래시 있는 수정은 Write/Edit 도구로. Git Bash에 strings 없음.
