# 이터널시티 (싱글플레이 팬 재현)

2003년작 2D 탑뷰 좀비 슈팅 MMORPG **이터널시티 1**을 브라우저에서 혼자 즐길 수 있게 재현하는 개인 프로젝트입니다.
Phaser 3 + TypeScript + Vite로 만들었고, 그래픽은 전부 코드로 그린 임시 스프라이트입니다(나중에 교체 가능).

> 비배포 개인용. 원작의 이름·세계관·시스템 명칭을 그대로 사용합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build && npm run preview   # 배포 빌드 미리보기 (4173)
npm test           # 유닛 테스트 (vitest)
npm run e2e        # 브라우저 e2e (playwright, preview 서버 자동 실행)
```

권장 사양: 내장 GPU 노트북(LG 그램)에서 1280×720 60fps 목표. 헤드리스 소프트웨어 렌더러 기준 222마리 동시 스폰 시 ~30fps.

## 조작

Esc 메뉴에서 두 방식을 언제든 전환할 수 있습니다.

| 원작식 (기본) | 현대식 |
| --- | --- |
| 좌클릭 이동 · NPC 클릭 = 대화 | WASD 이동 · E 대화 |
| Shift+클릭 달리기 · CapsLock 상시 달리기 | Shift 달리기 |
| 우클릭 공격 (마우스 방향) | 좌클릭 공격 |
| Space 웅크리기 → 다시 Space 점프 | C 웅크리기 · Space 점프 |
| Ctrl 서브연사 토글 | Ctrl 서브연사 토글 |
| I 인벤토리 · C 상태 · K 스킬 | I 인벤토리 · V 상태 · K 스킬 |

## 구조

```
src/core/   순수 TS 게임 규칙 (Phaser 금지, 전부 유닛 테스트)  stats · combat · weapons · inventory · skills · ai · assault · map · save
src/data/   콘텐츠 데이터 + 스키마 + balance.ts (부팅 시 validateAll로 참조 검증)
src/game/   Phaser 어댑터: scenes · entities · systems(InputMapper, CombatBridge, SpawnSystem) · ui(창들) · textures(코드 드로잉) · state
e2e/        Playwright 시나리오 (smoke · combat · windows · assault · save)
```

`window.__ec` 디버그 훅으로 상태 조회/스폰/텔레포트/어설트 진행을 제어할 수 있습니다(e2e에서 사용).
